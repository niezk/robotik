## 隐私政策

OrcaSlicer 桌面应用程序 · 生效日期：2026 年 6 月 12 日 · 版本 1.0

本隐私政策以英文版本为准并具有法律效力；中文翻译仅供参考。

OrcaSlicer 是一款面向 FDM 3D 打印机的免费开源切片软件，基于 AGPL-3.0 协议授权。它的设计初衷是完全在您的电脑上运行。本政策说明本应用程序对您的数据做了什么——以及特意不做什么。

本政策仅涵盖**OrcaSlicer 桌面应用程序**。可选的 Orca Cloud 服务受 [Orca Cloud 服务条款与隐私政策](https://cloud.orcaslicer.com/terms-and-privacy) 约束，该政策同样不适用于纯本地使用桌面应用程序的情形。

**简而言之：**&#x4F;rcaSlicer 可离线运行。您的 3D 模型、项目文件、G-code 及打印机设置均保存在您的设备上。本应用不收集任何遥测数据，也无需账号。它仅在您可见并可控的情况下连接互联网：更新检查、配置文件更新，以及您选择启用的打印机/云端集成。

### 2. 哪些内容保留在您的设备上

您在 OrcaSlicer 中创建或配置的一切内容都保存在您的电脑本地。除非您选择通过可选的 Orca Cloud 服务上传配置文件，否则我们永远不会看到您的模型、打印内容或设置。本应用不包含分析工具、广告 SDK 或使用情况追踪功能，也不会在后台联网回传数据。

### 4. 我们不会做的事

* 桌面应用中没有遥测、使用统计或行为分析。本应用甚至会在第三方 Bambu 网络插件启动前，明确禁用其遥测功能——这一点可在源代码中验证。
* 使用 OrcaSlicer 无需账号或注册。
* 不出售、出租或分享个人数据——因为我们没有可出售的数据。
* 没有广告或第三方追踪 SDK。
* 不会自动上传崩溃转储文件。如果应用崩溃，您可&#x4EE5;_&#x9009;&#x62E9;_&#x901A;过 GitHub issue 与我们分享日志；您在那里发布的任何内容都是公开的，并受 GitHub 隐私政策约束。

### 5. 第三方服务

部分可选功能依赖第三方，每项服务均有各自的隐私政策：

* **Orca Cloud** — 我们提供的可选配置文件备份、同步与分享服务，由 OrcaSlicer Pte. Ltd. 依据 [Orca Cloud 服务条款与隐私政策](https://cloud.orcaslicer.com/terms-and-privacy) 运营。
* **GitHub** — 托管我们的发行版、配置文件及问题跟踪系统。
* **Bambu Lab** — 为 Bambu 打印机提供专有的 Bambu 网络插件及云服务。
* **您自己的打印主机软件**（OctoPrint、Moonraker、PrusaLink、Duet 及类似软件）— 运行在您自己控制的硬件上。
* **云打印服务**（SimplyPrint、Obico、Prusa Connect 及类似服务）— 您使用自己的账号配置的可选集成；您发送的数据将进入这些服务，并受其各自政策约束。

我们建议您在启用这些功能前先查阅其相应政策。禁用或不配置它们不会限制核心切片功能。

如果您认为我们持有关于您的个人数据（例如，来自您发给我们的支持邮件），您有权要求访问、更正或删除该数据：
