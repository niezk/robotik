## Add Objects[¶](prepare-toolbar.md#add-objects) <a href="#add-objects" id="add-objects"></a>

Choose one or more files (3MF/STEP/STL/SVG/OBJ/AMF) to import into the current project as [Object Sets](/broken/pages/a8af0b8ce0249203e2777bb45c50be863fbaa112).

Tip

See [Import and Export](/broken/pages/f2c68b382bf7caa0d1c1d0addfed2d60d9583c14#import-model) for more information about supported file formats and import methods.

## Add Plate[¶](prepare-toolbar.md#add-plate) <a href="#add-plate" id="add-plate"></a>

Adds a new print plate to the current project.

## Measure Tool[¶](prepare-toolbar.md#measure-tool) <a href="#measure-tool" id="measure-tool"></a>

Use the Measure Tool to measure distances between points/edges/faces on your 3D model.
