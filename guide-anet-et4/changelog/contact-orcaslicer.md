# Contact OrcaSlicer

Development

## Bugs & feature requests — on GitHub

OrcaSlicer is developed in the open. Please file bugs and feature requests as GitHub issues — not by email — so they can be triaged, tracked, and found by other users.

### Report a bug

Found an issue? Help improve OrcaSlicer by filing a detailed bug report on GitHub.

[Report bug](https://github.com/OrcaSlicer/OrcaSlicer/issues/new?template=bug_report.yml)

### Request a feature

Have an idea? Share your suggestion and help shape the roadmap.

[Request feature](https://github.com/OrcaSlicer/OrcaSlicer/issues/new?template=feature_request.yml)

### Contribute on GitHub

Browse the source, review pull requests, or send your own.

[Open repository](https://github.com/OrcaSlicer/OrcaSlicer)

## Specific requests

### Security

If you discover a security vulnerability, report it privately to [security@orcaslicer.com](mailto:security@orcaslicer.com) or via a private GitHub security advisory. Please do not open a public issue.

### Media & press

For interviews, reviews, or press kits, email [contact@orcaslicer.com](mailto:contact@orcaslicer.com). Please include your publication and deadlines.

### Business & partnerships

Printer manufacturers and filament vendors can apply through the [Partner Program](get-your-brand-verified-and-your-profiles-official-in-orcaslicer.md). For other proposals, email [partners@orcaslicer.com](mailto:partners@orcaslicer.com).

### Privacy

For privacy questions or data requests, email [privacy@orcaslicer.com](mailto:privacy@orcaslicer.com).

### Verify official channels

The only official OrcaSlicer sites are **www.orcaslicer.com** and **cloud.orcaslicer.com**. Verified releases are on our official GitHub Releases page. Beware of impersonation sites.
