# Cloud Plugins¶

Cloud plugins are plugins connected to your OrcaCloud account. They can be subscribed to from the cloud plugin browser, then installed and activated inside OrcaSlicer.

## Browse Cloud Plugins[¶](cloud-plugins.md#browse-cloud-plugins) <a href="#browse-cloud-plugins" id="browse-cloud-plugins"></a>

1. Sign in to OrcaCloud.
2. Open **File** > **Plugins**.
3. Click **Browse plugins**.
4. Subscribe to the plugin you want from the cloud plugin browser.
5. Return to OrcaSlicer and click **Refresh** if the plugin list has not updated.

Subscribed plugins appear with a **Subscribed** source label. A subscribed plugin may show **Not installed** and **Inactive** until you activate it.

![cloud-plugin-subscribed-inactive](<../../.gitbook/assets/cloud plugin subscribed inactive.png>)

To use a subscribed plugin, check its **Activate** box. OrcaSlicer installs or loads the plugin as needed.

![cloud-plugin-loading](<../../.gitbook/assets/cloud plugin loading.png>)

When activation is complete, the plugin status changes to **Activated**. Expand the plugin row to see the available plugin features.

![cloud-plugin-update-available](<../../.gitbook/assets/cloud plugin update available.png>)

## Update a Cloud Plugin[¶](cloud-plugins.md#update-a-cloud-plugin) <a href="#update-a-cloud-plugin" id="update-a-cloud-plugin"></a>

If a newer cloud version is available, the plugin details show an **Update** button.

![cloud-plugin-update-available](<../../.gitbook/assets/cloud plugin update available.png>)

Click **Update** and wait for the update to complete.

![cloud-plugin-updating](<../../.gitbook/assets/cloud plugin updating.png>)

After updating, the installed version and latest version should match.

![cloud-plugin-updated](<../../.gitbook/assets/cloud plugin updated.png>)
