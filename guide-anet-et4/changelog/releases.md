# Releases¶

Release notes for each version of OrcaSlicer, newest first. Select a version to read the full changelog.

## History[¶](releases.md#history) <a href="#history" id="history"></a>

Note

A stable release includes every feature from its earlier alpha and beta builds, but the stable changelog only lists what changed since the last stable release — it does not repeat those alpha and beta features.\
To see everything new between one stable release and the next, read the accompanying alpha and beta notes as well.

* [**V2.5.0 Alpha**](/broken/pages/c4cd1c3daa6c7dc9e66f0dd5bd9f8246fc5306f9) — The most feature-packed release yet: Python plugins, belt printing, the experimental Design tab, color mixing, Texture Displacement, and IDEX/IQEX parallel printing.
* [**V2.4.2**](/broken/pages/5a4d65691eaa60a5a08511c6f69cf043e56f8114) — Maintenance update focused on more dependable profiles, cloud sync, and printer connectivity, plus several crash fixes.
* [**V2.4.1**](/broken/pages/d27dd15a8ad72bee931288b4efa3be0fbc1a2e00) — Maintenance update with a broad round of profile and preset fixes, a native Windows ARM64 build, and a reworked skirt and brim generator.
* [**V2.4.0**](/broken/pages/4f55fad468813a2f8b8cd3d5778fb38a7dedc239) — Bug fixes, a smoother Orca Cloud experience, and the ability to send sliced jobs to the printer as a packaged 3MF.
  * [**V2.4.0 Beta**](/broken/pages/89309c192213ffa9cba586500165b1ae36a82ec5) — Stability, speed, and print-quality work — greatly improved bridging and a new realistic rendering option.
  * [**V2.4.0 Alpha**](/broken/pages/c8090e421385b319a2266db39af8f059fea7b58c) — Introduces Orca Cloud (profile sync and sharing), Z Anti-Aliasing contouring, an Expert user mode, and native Wayland support for Linux.
