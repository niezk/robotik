# 每一层，都精准如你所愿。

功能集

## 为精益求精的打印玩家而生

OrcaSlicer 将打印质量视为一个工程问题：测量、调整、控制——精确到每一面墙、每一条接缝、每一层。

01 / 校准

### 轻松调校任意打印机

不必再下载测试模型。校准实验室已内置于切片软件中，调校新打印机或新耗材只需几分钟，而不是一整晚。

#### 内置校准套件

流量、压力提前、温度塔、回抽、容差、最大体积流量测试——均可在切片软件内生成并评估。

#### 自适应网床

仅探测打印件所在区域，无需每次都进行整个热床调平，也能保证首层精准。

#### 鼠标耳帽檐

自动生成、易于去除的帽檐，可固定易翘边模型的边角——增强附着力又不留清理麻烦。

02 / 打印质量

### 掌控每一层

好的打印品和卓越打印品之间，往往只差几个大多数切片软件都没有开放的设置项。OrcaSlicer 把它们都开放给你。

#### 墙与接缝控制

调整外墙间距并采用斜拼接缝，让接缝痕迹几乎从模型表面消失。

#### 智能支撑

智能悬垂检测与精准支撑布局，应对复杂几何结构——需要的地方够牢固，不需要时轻松移除。

#### 三明治模式与多边形孔

交替墙与填充打印顺序，让悬垂更整洁；打印出的孔径与 CAD 设计尺寸完全一致。

#### 分特征参数覆盖

为墙、填充、支撑等特征分别独立设置速度、层高、压力和温度。

03 / 工作流程

### 从桌面到打印机

切片软件应该适配你的工作环境，而不是反过来——无论你使用什么型号的打印机。

#### 网络打印

向运行 Klipper、PrusaLink 或 OctoPrint 的打印机发送任务并进行监控——无需来回插拔 SD 卡。

#### 数百款打印机预设

为 Bambu Lab、Prusa、Creality、Voron 等众多品牌提供调校好的预设，并由社区共同维护。

#### 熟悉的工作界面

拖拽、摆放、切片。只要用过现代切片软件，你就能轻松上手。
