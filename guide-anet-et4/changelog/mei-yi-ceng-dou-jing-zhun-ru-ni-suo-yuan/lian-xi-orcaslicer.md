# 联系 OrcaSlicer

开发

## Bug 与功能建议 — 请前往 GitHub

OrcaSlicer 采用公开开发模式。请通过 GitHub Issue 提交 Bug 与功能建议，而不是发送邮件，这样才能被分类、跟踪，并让其他用户查阅。

### 反馈问题

发现问题了吗？提交详细的 Bug 报告，帮助改进 OrcaSlicer。

[反馈问题](https://github.com/OrcaSlicer/OrcaSlicer/issues/new?template=bug_report.yml)

### 提交功能建议

有好点子？分享你的建议，帮助规划产品路线图。

[提交建议](https://github.com/OrcaSlicer/OrcaSlicer/issues/new?template=feature_request.yml)

### 参与 GitHub 贡献

浏览源代码、审阅拉取请求，或提交你自己的贡献。

[打开代码仓库](https://github.com/OrcaSlicer/OrcaSlicer)

## 特定事宜咨询

### 安全问题

如果你发现安全漏洞，请私下报告给 [security@orcaslicer.com](mailto:security@orcaslicer.com)，或通过 GitHub 私密安全公告提交。请勿公开发布 Issue。

### 媒体与新闻

如需采访、评测或媒体资料包，请发送邮件至 [contact@orcaslicer.com](mailto:contact@orcaslicer.com)，并附上你的媒体名称与截止日期。

### 商务与合作

打印机制造商与耗材厂商可通过[合作伙伴计划](../wei-ni-de-pin-pai-wan-cheng-ren-zheng-rang-ni-de-yu-she-cheng-wei-orcaslicer-guan-fang-yu-she.md)申请。其他合作提案，请发送邮件至 [partners@orcaslicer.com](mailto:partners@orcaslicer.com)。

### 隐私

如有隐私相关问题或数据请求，请发送邮件至 [privacy@orcaslicer.com](mailto:privacy@orcaslicer.com)。

### 核实官方渠道

OrcaSlicer 唯一的官方网站是 **www.orcaslicer.com** 和 **cloud.orcaslicer.com**。经过验证的正式版本可在我们官方的 GitHub Releases 页面获取。请警惕仿冒网站。
